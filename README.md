# 📸 Adasa Blog

A modern and responsive photography blog built with **React.js** and **Vite**, designed to provide an elegant reading experience for photography enthusiasts. The project focuses on performance, clean UI, and a seamless user experience across all devices.

---

## 🚀 Overview

Adasa Blog is a single-page application (SPA) that allows users to browse, search, and explore photography articles through a clean and intuitive interface. It demonstrates modern front-end development practices using React and Vite.

---

## ✨ Features

* 📚 Browse photography articles
* 🔍 Search posts instantly
* 🗂️ Filter articles by category
* 📄 Dedicated blog details page
* 📱 Fully responsive design
* ⚡ Fast development and optimized performance with Vite
* 🎨 Modern and clean user interface
* ⬆️ Automatic scroll-to-top navigation
* 🚫 Custom 404 Not Found page
* 🌙 Smooth user experience with optimized routing

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/mohamed-mahmoud-28/adasa.git
```

Navigate to the project directory:

```bash
cd adasa
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
